# 课程要求全文：INT6181 应用 Python 程式设计 · 小组项目作业

来源：《INT6181小组项目作业要求说明.pdf》（3 页，与 `python group assignment.pdf` 为同一文件）。下面按原文整理，页码标在各节后；本项目的对应安排见 [任务安排](team-tasks.md) 第 8 节。截止日期、组员人数和汇报时间以 Moodle 为准，PDF 没有写。

## 1 介绍（第 1 页）

该小组项目作业挑战你应用 Python 编程和现代软件工程实践去开发一个实际应用程式。与基础编程项目不同，该项目不仅强调小组解决问题的能力，还注重软件质量。

每个小组将设计一个基于命令行界面（CLI）或图形界面（GUI）的 Python 应用程序，结合 AI 来实现与执行，并进行全面评估及撰写专业的文档。

## 2 建组（第 1 页）

每个小组应由 Moodle 中规定的学生人数组成。

## 3 评分标准

### 3.1 原创性和实用性（10%）（第 1 页）

该应用程序应解决一个实际问题（区别于其他小组）。它应该功能齐全（功能性）、用途明确（目的性），并且可以作为独立程序使用（可用性）。此外，在小组演示汇报（presentation）和报告（report）中解释该应用程序的用途将很有帮助。

### 3.2 可用性（10%）（第 1 页）

- **正确执行**：程序必须完全可以运行且不会发生崩溃。它应该能在标准 Python 环境中正确执行。
- **易用性**：应用程序应包含清晰直观的用户界面，让用户能够轻松上手。必要时应提供操作说明。
- **错误处理**：程序应恰当地处理无效输入，并提供有意义的错误提示信息，而非崩溃。
- **响应性**：应用程序应及时向用户反馈，以确保处理输入和显示输出过程中不出现非必要的延迟。

### 3.3 技术的深度与难度（55%）（第 1–2 页）

小组项目将根据其中运用了多少本课程中的高级技术进行评估：

| 难度等级 | 应用编程中的预期技术 |
| --- | --- |
| 最低限度（Minimum） | 内容有意义的基本输出 |
| 边缘（Marginal） | 最低限度 + 输入（键盘/文件）和计算 |
| 满意（Satisfactory） | 边缘 + 模块化（函数/类/模块） |
| 优良（Good） | 满意 + 符合规格与测试要求 |
| 卓越（Excellent） | 优良 + 文档和代码审查 |

在规范制定、测试、持续集成/持续交付（CI/CD）、文档编写和/或代码审查中使用生成式人工智能将获得奖励。

### 3.4 小组演示汇报（20%）（第 2 页）

演示汇报应当结构清晰，包括引言、问题描述、技术方法、演示和结论，重点突出应用程序的实用性、易用性和在实际场景中的适用性。小组也应提供应用程序实际操作与使用过程的演示，重点展示其主要特性和功能。演示汇报时间应控制在 **15 分钟以内，并以视频形式提交**。

小组应在课堂上 **5 分钟内用最多 5 张幻灯片** 展示项目的关键技术方面，例如从本课程中学到的先进技术。报告者应使用简洁明了的语言，确保听众理解项目内容。小组需要回答老师和同学提出的问题。

这部分由同学和老师共同评估。每位学生都必须参加同行评审（peer review），不参与可能会影响个人成绩。

### 3.5 个人报告（5%）（第 2 页）

每位成员都必须撰写一份 **至少 1000 字** 的个人报告，描述和解释自己的贡献。格式包括：引言、项目描述、个人贡献、面临的挑战、经验教训和结论。报告应清晰描述个人角色和贡献，具体说明参与了哪些任务、如何为最终成品做出贡献；可以反思学到了什么、编程技能如何提升、下次会做哪些不同的事情。

## 4 提交（第 2–3 页）

每组只需一名成员提交小组部分。逾期提交的材料可能不被接受。

### 4.1 小组完成部分

1. **项目提案**：在 Moodle 简要描述小组将尝试做什么，并列出组员姓名和学生 ID。提交提案的学生成为该组联络人。
2. **源代码**：
   - 起始 Python 文件命名为 `main.py`；
   - 运行说明写在 `README.md`；
   - 全部文件（源文件、数据文件和说明文件）压缩为 `groupX_project.zip`；
   - 在 Moodle 上提交项目代码和测试用例。
3. **小组汇报**：`groupX_presentation.pptx`、`groupX_presentation.pdf` 和视频 `groupX_presentation.mp4`。

### 4.2 个人完成部分

- 报告：Moodle 提交 PDF，`groupX_report_xxxxxxxx.pdf`（第 3 页称“小组报告”，第 2 页 3.5 要求每人至少 1000 字的个人报告；按每人独立撰写准备）。
- 同行评审：在 Moodle 选择和提交你最感兴趣的小组项目。

## 5 人工智能与抄袭政策（第 3 页）

所有提交的作品必须为原创，且由所有小组成员共同创作。可以在项目的所有代码功能中自由地与生成式人工智能协作。任何其他形式的抄袭均被严格禁止。使用外部资源（例如第三方库或开源代码）必须在报告中正确引用，并确保其符合项目要求。
