# 《雾港旧案 · 影像版》剧情结构

负责人：ZC。插件：`mystery`（线索、分幕、带理由的指认）。本文件给组员看，含剧透。

这是影像模式（`cinematic.html`）专用的线性分支版：人物、案情和真相与 `stories/fog_harbor/` 相同，但每个选择都进入下一段剧情，不能回头。`stories/film/` 下的剧本不出现在文字版书架、桌面和命令行菜单；`python main.py validate` 与 CI 会校验并回放它们，`tests/integration/test_film_stories.py` 检查场景图无回路。

## 分支图

```text
第一幕 · 雾夜
大堂 ─┬─ 推开账房的门 ───────────────┐
      └─ 先盘问顾先生（说辞、湿裤脚）─┴─► 账房（伤口、消失的镇纸）
账房 ─┬─ 账本（撕页、对不上的数目）─┬─ 去后厨找周文
      │                              └─ 上楼搜客房
      └─ 窗户（盐泥）───────────────┬─ 上楼搜客房
                                     └─ 后院（脚印）─┬─ 皮鞋印 → 客房
                                                      └─ 布鞋印 → 阿芸
客房（湿外套）─┬─ 当面质问顾先生（供述）─┬─ 去后厨 → 周文
               │                          └─ 等天亮交给警署 → 结局 dawn
               └─ 放回外套 → 周文
周文（不在场证明）─┬─ 追问亏空（需对不上的数目）─┬─ 搜他的房间（暗账、便条）→ 退潮
                   │                              └─ 去问阿芸
                   └─ 去问阿芸
阿芸 ─┬─ 去阁楼（阿水的信、砒霜收条）→ 退潮
      └─ 回大堂 → 退潮

第二幕 · 退潮（大堂）
├─ 摸水缸（需顾先生的供述）：镇纸、存货亏空 ─┬─ 出示镇纸给周文（失言）─┬─ 问阿芸（需信）
│                                             │                          ├─ 下码头
│                                             │                          └─ 对质
│                                             └─ 对质
├─ 拿信问阿芸（需信）→ 阿芸的实话 → 对质
├─ 下码头（船家记事本）─┬─ 问阿芸 → 阿芸的实话 → 对质
│                       └─ 对质
└─ 直接对质

对质：指认 + 动机／手段／关键证据，或“不作指认” → 结局 dawn
```

## 结局

| 结局 | 条件 | 通关脚本 |
| --- | --- | --- |
| `truth` 雾散 | 指认周文；动机“挪用账款被发现”（需对不上的数目、存货亏空或暗账之一）、手段“用铜镇纸击打后脑”、证据“水缸里的镇纸”或“周文的失言”；且已得到阿芸的实话 | `truth.txt`（账本线）、`truth_window.txt`（窗台线） |
| `insufficient` 雾未散 | 指认周文，但理由不全对或没有打破不在场证明 | `insufficient.txt` |
| `scapegoat` 替罪羊 | 指认顾先生 | `scapegoat.txt` |
| `wrong` 错认 | 指认阿芸 | `wrong.txt` |
| `dawn` 交给天亮 | 质问顾先生后把他交给警署，或对质时不作指认 | `dawn.txt` |

真相的关键是“顾先生的供述”：不当面质问他，第二幕就不会想到去摸水缸。
