# 《雾港旧案：未结的账》影像版：结构与交接

负责人：ZC。剧本文字来自 Codex 的《完整剧本初稿》0.1；本目录是它的可运行版本，含剧透。

- 播放：`/cinematic`（默认就是本剧）；旧样片 `/cinematic?story=fog_harbor_film`，深空 `/cinematic?story=deep_space_film`。
- 校验与回放：`python main.py validate`；`tests/integration/test_ledger_film.py`；8 条通关脚本在 `walkthroughs/`。
- 数据：50 个场景（序章 P01–P04、五幕 A–E、尾声 F01–F05）、49 条线索、22 个调查步骤（`units`，由 `taleloom/mechanics/mystery.py` 判定）、5 个结局、5 个存档点。

## 调查单元（剧本的 10 个单元）

| 剧本单元 | `units` id（场景） | 玩家操作 | 判定要点 |
| --- | --- | --- | --- |
| 行李签核对 | `tags`（p02） | 查看两张签与寄存簿，选签、行、多出的一件 | 完成后记“周左袖补丁完整” |
| 灯下残页 | `lamp`（a03） | 查看窄边、纸背、信封，把三处分栏记下 | 300 与 584 合并时提示“两面标题不同” |
| 纸片拼合 | `paper`（b01_paper／b05，可延后） | 选朝上的一面与撕边位置 | 只在顾交出或见证下查看后进行 |
| 证词与时间线 | `claims`（b02）、`duty`（b04）、`timeline`（b06） | 选需复核的原话；核对人名、地点、见证范围；六件事排先后（可拖动） | 周的“一直到二十分”只记为本人陈述 |
| 三笔钱核对 | `batch`（c01）、`sums`（c05） | 选同一批次的两份材料；300/384/340 分栏，说明 724 | 724 可暂记待查（档次 partial） |
| 旧名册复核 | `roster`（c03_roster_a／b） | 指出站不住的记载与对照材料 | 字迹相似不能当依据 |
| 后厨水缸 | `vat`（d01）、`weight`（d02） | 观察三处痕迹，排取物步骤；以刻字与旧修补认物 | 先见证，再开盖、照灯、长柄工具 |
| 衣料比对 | `sleeve`（d02_sleeve） | 选两项细节比对 | 颜色只算初步观察；拒绝路线不发完整匹配 |
| 材料封存 | `seal`（d04_seal）、`box`（d04_box） | 分袋封存；原件缺失时在见证下查票箱 | 两件物证分开包 |
| 最终对质 | `q_time`、`q_object`、`q_person`、`q_motive`（e02_zhou）；`q_gu`、`q_ayun` | 每问从“已取得”的线索里选依据 | 四问都为 full 才进入“雾散”；弱答案要再次确认 |

另有两个只查看不核对的地方：`scene_a01`（发现现场）、`window`（后窗）。

## 路线与结局

| 通关脚本 | 路线 | 结局 |
| --- | --- | --- |
| `truth` | 信任沟通，含错答、合并、提示 | `truth` 雾散（旧款完整附段） |
| `truth_guarded` | 搜顾口袋→顾拒答；当众念信→阿芸修复路线；周不交小册；让周整理→查票箱找回；周保持否认 | `truth`（旧款待查附段） |
| `truth_later` | 纸片延后到 B05；先读旧名册 | `truth` |
| `insufficient` | 抓周的袖子→拒绝比对，仍指认周 | `insufficient` 雾未散（只列真实缺项） |
| `scapegoat` | 原件整箱封存；指认顾 | `scapegoat` 错置的账 |
| `wrong` | 指认阿芸 | `wrong` 被误读的人 |
| `dawn` / `dawn_pending` | 不作指认（保全充分／不足） | `dawn` 交给天亮 |

存档点：一 · 夜深取账（a01）、二 · 旧账（c01）、三 · 后厨（d01）、四 · 对质之前（e01）、五 · 最后签字（e04_funds）。

## 给剧本负责人（Codex）的问题

实现时按下列假设处理，请确认或修改：

1. **B03 公开念信的触发**：剧本没写何时“公开私信”。现在在 B02 结尾给玩家两个选择：私下问阿芸，或当众念她的信（进入修复路线）。
2. **顾拒绝陈述（B05）的条件**：未写。现在是 B01 未经同意搜口袋 → 顾此后拒谈账房里的事（`b05_silent`）。
3. **周拒绝展开袖口（D02）的条件**：未写。现在是玩家选择“抓住他的左袖，当场翻开”时拒绝；“在见证下请他展开”则同意。
4. **C04 周拒绝出示小册的条件**：未写。现在是玩家选择“要他当场交出来”。
5. **E03 自白版与否认版的条件**：未写。现在是事实链完整时，若 C04 他自愿出示过小账则开口，否则保持否认。
6. **失败惩罚与剧本冲突**：第二轮任务要求“选错有代价、可回退”，剧本明确“一次说错不会提前结束”。现在不设中途失败结局，代价体现为人物戒备、材料缺失和结局差异；会话的回到存档点照常可用。
7. **存档点编号**：剧本第四、第五个存档点都在“对质之前”。现在第四个在 E01，第五个在 E04（最后签字前）。
8. B06 “选出下一步要核对的两项”改为三选一的方向（不影响后续剧情），请确认是否需要真正的二选。
9. F02 复盘最多列三项缺口：四问都缺时只列前三问。

## 声音与画面素材

全部由代码生成，无外部文件，见 `web/runtime/THIRD_PARTY_NOTICES.txt`。

- 画面：Canvas 实时绘制（`web/cinematic/stage.js`），本剧新增饭桌 `dinner`、值房 `dutyroom`、账桌特写 `ledger`，以及饭后的账房 `office_alive`。画面键写在场景的 `art` 字段，例如 `portrait_zhou_cold_kitchen`。
- 声音：Web Audio 合成（`web/cinematic/sound.js`）：各场景环境声、配乐（舒缓／思索／紧张／沉郁／天亮），以及翻纸、落笔、落章、水声、核对未通过等拟音；静音与音量会记住；页面转入后台时暂停；重要声音在画面左下角显示文字说明。
- 未能使用的服务：本机没有 ElevenLabs 凭据，也没有图像生成服务，所以没有生成录音或插画。需要实录素材时可按下表补：雾笛、码头风浪、旅馆座钟、饭桌碗筷、灶火、雨夜窗、值房电话铃、翻账纸、毛笔落纸、印章、水缸探底、清晨船笛。
