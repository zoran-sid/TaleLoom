# 《雾港旧案：未结的账》影像版：结构与交接

负责人：ZC。剧本文字来自 Codex 的《完整剧本初稿》，已复核实现中的分支条件；本目录是它的可运行版本，含剧透。

- 播放：`/cinematic`（默认就是本剧）；旧样片 `/cinematic?story=fog_harbor_film`，深空 `/cinematic?story=deep_space_film`。
- 校验与回放：`python main.py validate`；`tests/integration/test_ledger_film.py`；8 条通关脚本在 `walkthroughs/`。
- 数据：50 个场景（序章 P01–P04、五幕 A–E、尾声 F01–F05）、49 条线索、22 个调查步骤（`units`，由 `taleloom/mechanics/mystery.py` 判定）、5 个结局、5 个存档点。

## 调查单元（剧本的 10 个单元）

| 剧本单元 | `units` id（场景） | 玩家操作 | 判定要点 |
| --- | --- | --- | --- |

| 灯下残页 | `lamp`（a03） | 查看窄边、纸背、信封，把三处分栏记下 | 300 与 584 合并时提示“两面标题不同” |
| 纸片拼合 | `paper`（b01_paper／b05，可延后） | 选朝上的一面与撕边位置 | 只在顾交出或见证下查看后进行 |
| 证词与时间线 | `claims`（b02）、`duty`（b04）、`timeline`（b06） | 选需复核的原话；核对人名、地点、见证范围；六件事排先后（可拖动） | 周的“一直到二十分”只记为本人陈述 |
| 三笔钱核对 | `batch`（c01）、`sums`（c05） | 选同一批次的两份材料；300/384/340 分栏，说明 724 | 724 可暂记待查（档次 partial） |
| 旧名册复核 | `roster`（c03_roster_a／b） | 指出站不住的记载与对照材料 | 字迹相似不能当依据 |
| 后厨水缸 | `vat`（d01）、`weight`（d02） | 观察三处痕迹，排取物步骤；以刻字与旧修补认物 | 先见证，再开盖、照灯、长柄工具 |
| 衣料比对 | `sleeve`（d02_sleeve） | 选两项细节比对 | 颜色只算初步观察；拒绝路线不发完整匹配 |

## 剧本分支复核（2026-11-09）

以下为 Codex 按剧本负责人分工完成的复核结果，供 ZC 人工试玩审阅：

1. **公开念信**：保留 B02 的公开／私下选择；补入阿芸主动拿出已拆信件并要求私谈的铺垫。公开路线明确为玩家拿起茶盘上的信念出首行，再进入关系修复。
2. **顾拒答**：保留“未经同意搜口袋 → 拒绝谈账房经过”。物证与短渡记录仍能独立推进；没有取得 `gu_account` 时，复盘与结局不再引用他的入室证词。
3. **周拒绝展开袖口**：保留“抓住左袖 → 拒绝”；见证下请求展开可以比对。拒绝路线不授予完整匹配线索，最终指认会留下实际缺口。
4. **周不交小册**：保留“要求当场交出 → 拒绝”。拒绝后通过其他账目继续调查，不授予小册用途细节；后续按钮统一改为“继续核对其余材料”，避免暗示已拿到抄件。
5. **自白与否认**：四问证据完整后，以此前是否自愿出示小册决定周是否愿意开口。这是人物沟通反应；两条路线都能得到有证据支持的“雾散”，自白不是定案门槛。
6. **选错的代价**：本剧完整经历调查阶段，以戒备、私人材料缺失、物证关联不足和结局差异体现代价。旧《雾港旧案 · 影像版》与《深空回声 · 影像版》的中途失败和回退机制继续适用。
7. **存档点**：第四点设在 E01 对质前，第五点设在 E04 旧款登记与最后签字前，避免两个点重复落在对质前。
8. **B06 下一步方向**：保留三个“两项组合”中选一组，已经表达了选出两项待核事项；后续仍会完成全部调查。
9. **F02 缺项复盘**：最多展开三条提问；四问全缺时，另明确标记第四项“当夜冲突”待查。缺动机时询问“为什么偏偏是今晚”，避免把已证实的人与现场关联误写为缺项。

## 声音与画面素材

全部由代码生成，无外部文件，见 `web/runtime/THIRD_PARTY_NOTICES.txt`。

- 画面：Canvas 实时绘制（`web/cinematic/stage.js`），本剧新增饭桌 `dinner`、值房 `dutyroom`、账桌特写 `ledger`，以及饭后的账房 `office_alive`。画面键写在场景的 `art` 字段，例如 `portrait_zhou_cold_kitchen`。
- 声音：Web Audio 合成（`web/cinematic/sound.js`）：各场景环境声、配乐（舒缓／思索／紧张／沉郁／天亮），以及翻纸、落笔、落章、水声、核对未通过等拟音；静音与音量会记住；页面转入后台时暂停；重要声音在画面左下角显示文字说明。
- 未能使用的服务：本机没有 ElevenLabs 凭据，也没有图像生成服务，所以没有生成录音或插画。需要实录素材时可按下表补：雾笛、码头风浪、旅馆座钟、饭桌碗筷、灶火、雨夜窗、值房电话铃、翻账纸、毛笔落纸、印章、水缸探底、清晨船笛。

## 交接状态（2026-11-09）

已实现：调查单元、剧本与 8 条通关脚本、正式会话存档与回退、调查台动画、程序化画面和声音。Codex 已复核上述 9 项分支，并修复以下问题：

- 没取得顾的入室陈述时，部分复盘和结局仍引用了该陈述；公开念信和小册拒绝路线也已补齐铺垫与按钮文案。
- 缺动机时的提问误指向人与现场关联；四问全缺时第四项被静默省略。
- 恢复存档／重新开始后，调查台保留后续的本地观察记录、答案草稿和错误反馈；核对成功后草稿未清除。
- 同时开始的环境声与配乐相互覆盖字幕。
- 浏览器测试中被调查台覆盖的点击目标，以及重绘后指向其他选项的复选框定位。
- Linux 字体下排序卡片高度不足（现明确至少 44px）；调查台淡入结束后再交付键盘焦点，关闭时清理入场动画。

验证命令与最新结果记录在 [PR #32](https://github.com/zoran-sid/TaleLoom/pull/32)。浏览器自动测试包括完整通关、五种结局、手机横竖屏、键盘、减少动态效果、存档回退和声音状态。

人工验收由 ZC 负责（2026-11-09 调整）：桌面与手机试玩、画面截图、实际听感及首次游玩时长。各幕分钟数仍是设计目标，尚未实测；快速模式的自动通关耗时不代表玩家时长。
