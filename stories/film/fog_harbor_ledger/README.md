# 《雾港旧案：未结的账》影像版

负责人：ZC。当前玩法按 2026-11-10 的设计调整：玩家通过对话、调查方向、证物保管和最后签字推进剧情。线索发现、账目关系与对质回应融入场景，不再弹出调查台要求排列、配对、填答或提交核验。

- 入口：`/cinematic`；旧雾港样片为 `/cinematic?story=fog_harbor_film`，深空为 `/cinematic?story=deep_space_film`。
- 规模：50 个场景、49 条线索、5 个结局、5 个存档点；8 条通关脚本在 `walkthroughs/`。
- 剧本依据：原创《完整剧本初稿》。初稿中的交互核验步骤已由本次调整替代，以本目录的 `story.json` 和说明为准。

## 发现与推理如何展开

到达相应场景后，行李签、残页、时间记录、账目、水缸与封存过程直接展开，并把事实记入笔记。纸片延后查看时，必须先取得短渡记录，再回到顾面前；袖口匹配只出现在周同意见证比对的路线。剧情不会因为删除核验而提前发放被拒绝的材料。

最终对质根据已有线索展示时间、物件、人与现场、当夜冲突四组论证。结局读取实际取得的事实，不读取旧调查单元的答题档次。公开念信、未经同意搜口袋、强抓袖口、材料交给谁、是否指认以及如何登记旧款，继续影响人物反应、材料和结局。

新游戏不产生 `mystery.units`。引擎的可选调查单元能力保留给其他剧本与既有存档；本剧不启用它。读旧档仍可在原场景继续，离开场景时会补记当前剧情已经展示的事实。重新开始可体验连贯的新版演出。

## 九处分支的确认结果

这九项已复核并落实，供后续维护和 ZC 人工试玩使用。

1. **公开念信**：阿芸先把已拆信件放到茶盘旁并请求私谈。公开路线是玩家主动拿信念出首行，随后她收回私人材料；行踪可通过值房记录与她的三项事实补证。
2. **顾拒答**：未经同意搜口袋后，顾只承认乘短渡，拒谈账房经过。纸片仍在见证下取得；复盘与结局只在取得 `gu_account` 时引用他的入室陈述。
3. **周拒绝展开袖口**：请求见证比对可记录裂边、针脚与织纹匹配；强抓会被拒绝，只能记下可见破口。拒绝路线保留真实缺项。
4. **周不交小册**：要求当场交出会触发拒绝，新款用途仍未知；供货差额与旧账材料可以继续调查。按钮不暗示已取得抄件。
5. **自白或否认**：四组事实完整后，自愿出示小册的周会开口，拒交小册的周仍保持否认。两条路线都可进入“雾散”，自白不构成额外门槛。
6. **选错的代价**：本剧不设中途失败。代价是人物戒备、私人材料缺失、证物关联不足与结局变化；旧雾港样片和深空影像版沿用各自的失败机制。
7. **存档点位置**：第四点在对质前，第五点在旧款登记与最后签字前，分别支持重选指认与最终处理。
8. **B06 调查方向**：保留三个后续调查方向选择，记录玩家当下的判断；后续都会经过账目与镇纸调查。时间线在剧情中展开，不再拖动排序。
9. **证据不足的复盘**：按实际缺少的事实列出最多三条追问；四项全缺时另列当夜冲突待查。缺动机时追问“为什么偏偏是今晚”，不会把已经证实的人与现场关联写成缺项。

## 音画与后续素材增强

当前画面与声音继续使用现有代码生成方案，运行时不依赖外部素材服务，也不需要 ElevenLabs 或图像生成凭据。

- Canvas 画面在 `web/cinematic/stage.js`，场景通过 `art` 字段选用。
- Web Audio 声音在 `web/cinematic/sound.js`，保留环境声、配乐、拟音、静音和音量记忆、后台暂停及声音字幕。
- 后续可按需加入实录音效或插画，属于体验增强，不是当前版本的待完成依赖。引入时记录来源、许可证和文件用途，并保留现有静音、字幕及减少动态效果支持。

| 可增强的素材 | 对应场景 |
| --- | --- |
| 雾笛、码头风浪、清晨船笛 | 港口开场与尾声 |
| 座钟、碗筷、灶火、雨夜窗 | 旅馆、饭桌、后厨与夜间场景 |
| 电话铃、翻账纸、毛笔落纸、印章 | 值房、账桌与封存 |
| 水缸探底、人物与场景插画 | 取物段落及人物对话 |

## 存档与验收

`taleloom/save.py` 已检查 `mystery.units` 的对象层级、观察点字符串列表、非负整数次数、完成档次与上次答案。坏档被拒绝，当前游戏保持原状；存档点和上一步记录也经过同一检查。没有 `units` 的旧档及结构正确的已停用单元仍可读取。

自动检查入口：`python main.py validate`、`python main.py replay fog_harbor_ledger`、`tests/integration/test_ledger_film.py`、`tests/browser/cinematic-ledger.spec.js`。覆盖八条路线、五种结局、事实出现时机、存档回退、手机尺寸、键盘、声音状态及本地资源加载。

ZC 负责桌面与手机实际试玩、画面截图和听感检查。首次游玩仍以 30 分钟以上为目标；删除核验步骤后需要重新计时，各幕时长不能当作实测结果。自动快速通关只验证逻辑。
