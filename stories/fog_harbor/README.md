# 《雾港旧案》剧情大纲

负责人：ZC。插件：`mystery`。本文件给组员看，含剧透。

一九三一年，雾港海鸥旅馆。午夜，陈掌柜死在账房，警署天亮才能上岛。玩家是唯一的客人。16 个场景、21 条线索、两幕、5 个结局。

## 人物与秘密

| 人物 | 表面 | 秘密 | 在哪里审问 |
| --- | --- | --- | --- |
| 顾先生 | 外地商人，欠掌柜三百块大洋 | 十一点二十分翻窗进账房想撕欠条，发现人已经死了，撕走账页后逃走 | 大堂、对质 |
| 周文 | 账房先生，自称与阿芸在后厨待到十一点 | 挪用了近四百块大洋，掌柜当晚发现并约他天亮去警署；十一点后独自用铜镇纸行凶，把镇纸藏进水缸 | 后厨、对质 |
| 阿芸 | 女招待，替周文作证 | 十一点从后门溜去码头见船家阿水；三天前买的砒霜只是药老鼠 | 后厨、对质 |

## 两幕

- **第一幕 · 雾夜**：现场（账页、盐泥、伤口、消失的镇纸）、顾先生的客房（湿外套）、阁楼、储藏室、后院脚印。线索几乎都指向顾先生。
- **第二幕 · 退潮**：向顾先生出示湿外套，他供出翻窗经过，时间线收紧到十一点到十一点二十分之间；此后可以摸水缸、撬周文的地板、下到码头看船家记事本。

## 推理链

1. 盐泥 → 检查外套 → 出示湿外套给顾先生 → **顾先生的供述**（进入第二幕）。
2. 消失的镇纸 → 深入调查后脑的伤 → 吻合的伤口；第二幕摸水缸 → **水缸里的镇纸**；出示给周文 → 周文的失言。
3. 深入调查账页 → 对不上的数目；储藏室 → 对不上的存货；第二幕撬地板 → 暗账 → 深入调查 → 掌柜的便条。
4. 阁楼木盒 → 阿水的信 → 出示给阿芸 → **阿芸的实话**（周文十一点后独自在后厨，不在场证明破产）。

误导线索：盐泥、湿外套、账页正面（指向顾先生）；砒霜收条（指向阿芸，深入调查后在储藏室得到澄清）。
