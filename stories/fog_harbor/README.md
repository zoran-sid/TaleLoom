## v0 序章（当前）

一九三一年，雾港海鸥旅馆。午夜，陈掌柜死在账房。玩家是唯一的客人。

| 人物 | 身份 | v0 中的作用 |
| --- | --- | --- |
| 顾先生 | 外地商人，昨天入住 | 凶手：欠陈掌柜巨款，从码头翻窗进账房想毁掉欠条 |
| 周文 | 账房先生 | 有不在场证明（与阿芸在后厨） |
| 阿芸 | 女招待 | 提供周文的不在场证明 |

推理链：账页残角（动机）+ 窗台盐泥 → 解锁检查外套 → 湿外套（手段与痕迹）→ 指认顾先生。

| 结局 id | 条件 | 通关脚本 |
| --- | --- | --- |
| `truth` | 指认顾先生，且有账页与湿外套 | `walkthroughs/truth.txt` |
| `insufficient` | 指认顾先生，证据不足 | `walkthroughs/insufficient.txt` |
| `wrong` | 指认周文或阿芸 | `walkthroughs/wrong.txt` |
