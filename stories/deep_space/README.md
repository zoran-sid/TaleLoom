# 《深空回声》剧情与回放

负责人：LQ。原创资源管理与道具解谜剧本，11 个场景（含 4 个结局）。

氧气初始 8，电量初始 20；实际行动每回合各消耗 1。查看不消耗资源。氧气罐一次补充 4，能源舱可一次充电 12，生命维持循环花费 3 电量换取 10 氧气。没有固定上限，因此公开资源不设置 max。

随机电力波动最多发生一次：消耗 1 电量。概率事件受存档中的 random_seed 和回合约束；通关脚本用 `# seed: 6181` 固定结果。两种资源耗尽时分别进入窒息或熄灯结局。

| 结局 | 达成条件 | 脚本 |
| --- | --- | --- |
| escape 回声 | 补氧、组合扳手、修复面板、进入逃生舱 | escape.txt |
| truth 有人听见 | 补氧充电、取得记录、电芯接通通信终端、发送记录后逃离 | truth.txt |
| suffocate 寂静 | 氧气耗尽 | no_tank.txt / wander.txt |
| blackout 熄灯 | 维持氧气但电量耗尽 | blackout.txt |

目标操作支持 `use 电芯 on 通信终端` 与中文“把 电芯 用在 通信终端 上”；桌面与网页通过相同结构化动作选择物品和目标。旧版“使用 修好的扳手”在气闸仍兼容。

验证：`python main.py validate`、`python main.py replay deep_space`；探索：`python -B -m taleloom.replay --seed 6181 --runs 20 --steps 100`。
