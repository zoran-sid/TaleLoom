负责人：LJ。插件：`puzzle`。本文件给组员看，含剧透。

## v0 序章（当前）

玩家在“回声号”空间站的休眠舱醒来，生命维持系统故障。氧气初始 8，每个消耗回合的行动减 1；降到 3 时警告，降到 0 进入窒息结局。

解法：储物柜拿胶带 → 工具间捡断扳手 → 组合成修好的扳手 → 到气闸门使用 → 进入逃生舱。
设计要点：**不接备用氧气罐，最短路线也会在修好面板的那一刻耗尽氧气**，玩家必须发现并使用氧气罐。

| 结局 id | 条件 | 通关脚本 |
| --- | --- | --- |
| `escape` | 修好面板并进入逃生舱 | `walkthroughs/escape.txt` |
| `suffocate` | 氧气耗尽 | `walkthroughs/no_tank.txt`、`walkthroughs/wander.txt` |
